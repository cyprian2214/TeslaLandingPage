🚗 Tesla Landing Page Clone

A responsive Tesla Model Y landing page clone built using HTML and CSS, designed to mimic the look and feel of Tesla's official site. This project includes a background video, smooth navigation, and styled call-to-action buttons.
🌐 Live Preview

📸 Features

    🔁 Full-screen looping background video

    🧭 Sticky top navigation bar

    ✨ Clean and modern layout with Tesla branding

    📱 Responsive design (mobile-friendly)

    📦 Icons and external fonts

    🔗 Social media integration

🛠 Technologies Used

    HTML5

    CSS3

    Google Fonts (Inter)

    SVG Icons

🧪 How to Use

    Clone the repository:

git clone https://github.com/yourusername/tesla-landing-page.git

Navigate to the project folder:

    cd tesla-landing-page

    Open index.html in your browser.

🎨 Customization

    Update the video in the Assets folder to change the background.

    Replace logos or links with your own content or brand.

    Style further using the style.css file.
